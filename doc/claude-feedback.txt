INTRODUCTION                                          *claude-feedback-intro*

Collect line-level code review comments and copy formatted batches to the
system clipboard for Claude Code or other tools.

Requires snacks.nvim, gitsigns.nvim (for diff-on-open), and git.

==============================================================================
COMMANDS                                              *claude-feedback-commands*

:ClaudeFeedbackAdd          Add review comment at cursor
:ClaudeFeedbackThread       Open thread float at cursor
:ClaudeFeedbackNext         Jump to next comment in buffer
:ClaudeFeedbackPrev         Jump to previous comment in buffer
:ClaudeFeedbackMenu         Quick menu
:ClaudeFeedbackPending      Pending picker with changed files
:ClaudeFeedbackCopy         Copy to clipboard (primary send)
:ClaudeFeedbackSetParent    Set parent/base branch
:ClaudeFeedbackDiff         Filtered explorer of changed files (vertical diff on open)
:ClaudeFeedbackResolved     Resolved batches
:ClaudeFeedbackClear        Clear pending comments

==============================================================================
KEYMAPS (defaults)                                    *claude-feedback-keymaps*

<leader>ra    Add review comment
<leader>rt    Open thread at cursor
<leader>rv    Quick menu
<leader>ry    Copy to clipboard
<leader>rd    Browse changed files
]r            Next review comment
[r            Previous review comment

==============================================================================
CONFIGURATION                                         *claude-feedback-config*

>lua
  require("claude-feedback").setup({
    changed_files = { mode = "both" },
    parent_branch = { fallback = "main" },
  })
<
