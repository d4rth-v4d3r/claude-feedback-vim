*claude-feedback.txt*  Code review comments for Neovim

==============================================================================
INTRODUCTION                                         *claude-feedback*

Collect line-level code review comments, copy a formatted batch to the
clipboard, and manage pending/resolved batches.

Use diffview.nvim or your preferred diff tool for side-by-side review.

Requires snacks.nvim and git.

==============================================================================
COMMANDS                                              *claude-feedback-commands*

:ClaudeFeedbackAdd           Add review comment at cursor
:ClaudeFeedbackThread        Open thread float at cursor
:ClaudeFeedbackNext          Jump to next review comment
:ClaudeFeedbackPrev          Jump to previous review comment
:ClaudeFeedbackMenu          Quick menu
:ClaudeFeedbackPending       Pending picker
:ClaudeFeedbackCopy          Copy batch to clipboard
:ClaudeFeedbackSetParent     Choose base/parent branch
:ClaudeFeedbackResolved      Resolved batches (rollback with r)
:ClaudeFeedbackClear         Clear pending comments

==============================================================================
KEYMAPS (defaults)                                    *claude-feedback-keymaps*

<leader>ra    Add review comment
<leader>rt    Open thread at cursor (reply/edit/delete inside)
<leader>rv    Quick menu
<leader>ry    Copy to clipboard
]r            Next review comment
[r            Previous review comment

Thread float: r=reply  e=edit  d=delete  q=close
Resolved picker: Enter=copy  r=rollback to pending

==============================================================================
CONFIGURATION                                         *claude-feedback-config*

>lua
  require("claude-feedback").setup({
    changed_files = { mode = "both" },
    parent_branch = { fallback = "main" },
    copy = {
      include_changed_files = false,
      changed_files_mode = "branch",
    },
  })
<
